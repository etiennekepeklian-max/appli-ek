# Pictogrammes de navigation Pikéo

Les neuf pictogrammes de `pikeo-actions-canva.png` ont été créés avec Canva le 30 octobre 2026 pour les boutons de l’application. Ils forment une grille de trois colonnes et trois lignes, utilisée localement par `simple-ui.css` ; aucun chargement Canva n’est nécessaire à l’usage.

Source Canva : https://www.canva.com/M/MAHZdpnGZco

Ordre : scanner, manquant, ENF ; code-barres, produit, picking ; mémo vocal, horaires, aide.

Les illustrations sont décoratives : les boutons portent tous un texte explicite et restent utilisables même si une image ne s’affiche pas. Cette planche ne remplace ni le logo de Pikéo ni la mascotte originale.
