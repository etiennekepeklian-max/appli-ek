Pikéo · Guide du bureau

La même application logistique sur un écran plus large, sans installation Android. Les données locales appartiennent au navigateur utilisé.

Ouvrir Pikéo BureauVersion mobileAide dans l’application

1. Démarrer

  1. Ouvrez l’espace bureau depuis un ordinateur, dans un navigateur récent.
  2. Utilisez le menu latéral : activité, catalogue, ENF, manquants, historique et sauvegardes.
  3. La loupe retrouve les fonctions ; le point d’interrogation fournit une aide adaptée à l’écran en cours.
  4. Sur le même navigateur, les versions bureau et mobile partagent le même stockage local. Sur un autre appareil, aucune donnée ne se transfère sans synchronisation ou restauration vérifiée.

2. Manquants et réassorts

  1. Saisissez commande, référence et quantité manquante. Le casier est facultatif.
  2. Vérifiez avant d’enregistrer. Un message professionnel préparé reprend la référence, la quantité, la commande et votre signature, jamais le casier.
  3. Pour corriger une erreur, utilisez Supprimer sur la fiche concernée, puis confirmez. Les autres fiches restent intactes ; l’annulation immédiate et l’historique restent possibles.

3. Produits, emplacements et ENF

  1. Recherchez les produits, les adresses PAC/PAD/RES et les compositions ENF.
  2. Dans Tous mes outils, choisissez Importer un catalogue par photo. Relisez les lignes détectées et résolvez les anomalies ; rien n’est importé sans validation.
  3. Les ENF nécessitent des compositions et quantités vérifiées. La photo d’une liste de concepts ne donne pas automatiquement la quantité exacte de chaque composant.

4. Sessions et sécurité

Ouvrez Sessions et collègues pour choisir votre espace. Le développement de l’administration renforcée et du code PIN sécurisé est encore en cours : ne présumez jamais qu’un simple nom prouve l’identité d’un administrateur. Les droits réellement appliqués dépendent du serveur.

5. Sauvegarder sans perdre mes données

  1. Terminez les formulaires et exportez une copie depuis Espace et sauvegardes avant les changements majeurs.
  2. Vérifiez la présence de vos photos et documents. Les mémos vocaux possèdent leur propre export.
  3. Sur votre téléphone, n’effacez ni le stockage du site ni les données de Chrome pour « actualiser » Pikéo.
  4. Les données locales de votre téléphone ne sont pas contenues dans un ZIP du code GitHub.
