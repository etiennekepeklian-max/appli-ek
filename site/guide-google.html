Activer la sauvegarde Google Sheets

Les fonctions de l’application sont disponibles sur cet appareil. Les étapes ci-dessous ajoutent la sauvegarde dans votre compte Google et la synchronisation avec d’autres appareils.

Ce qui est déjà prêt

Le code de synchronisation et la sauvegarde des photos privées sur Drive sont inclus. Dans les Réglages, renseignez l’URL ou l’identifiant de votre feuille privée, ou créez une nouvelle base après connexion. L’identifiant de la feuille reste sur votre appareil et ne figure pas dans le code public.

Il reste à créer un identifiant de connexion OAuth pour votre propre application. L’autorisation Google déjà donnée à ChatGPT ne peut pas être réutilisée par une application indépendante.

1 · Créer le projet Google

  1. Ouvrez Google Cloud Console avec votre compte.
  2. Créez un projet nommé EK Logistique.
  3. Dans API et services → Bibliothèque, activez Google Sheets API et Google Drive API.

2 · Préparer le consentement

  1. Dans Google Auth Platform ou Écran de consentement OAuth, indiquez le nom de l’application et votre adresse de contact.
  2. Pour un usage personnel, gardez le mode de test et ajoutez votre compte Google comme utilisateur de test.
  3. Les droits nécessaires sont https://www.googleapis.com/auth/spreadsheets et https://www.googleapis.com/auth/drive.file.

Le premier droit autorise la lecture et l’écriture des feuilles de votre compte. Le second ne concerne que les fichiers utilisés ou créés par l’application. L’interface Google peut évoluer et une application étendue à d’autres utilisateurs peut nécessiter une vérification supplémentaire.

3 · Créer l’identifiant Web

  1. Créez un ID client OAuth de type Application Web.
  2. Ajoutez les origines JavaScript autorisées : http://localhost:8765 pour le PC, puis l’origine HTTPS de votre site GitHub Pages pour le téléphone.
  3. Une origine ne contient pas le chemin du dépôt : pour https://votre-compte.github.io/appli-ek/, l’origine est https://votre-compte.github.io.
  4. Copiez l’identifiant finissant par .apps.googleusercontent.com dans les Réglages de EK Logistique.

Ne copiez aucun secret client dans l’application. Le modèle de connexion utilisé par le navigateur n’en a pas besoin.

4 · Connecter et vérifier

  1. Renseignez l’URL ou l’identifiant de votre feuille privée dans les Réglages. Si vous n’avez pas encore de base, vous pourrez en créer une après connexion.
  2. Enregistrez les réglages puis touchez Connecter mon compte.
  3. Choisissez le compte propriétaire de la feuille et vérifiez les droits demandés.
  4. Ajoutez une fiche d’essai clairement identifiée, puis synchronisez.
  5. Vérifiez qu’une ligne apparaît dans l’onglet correspondant du Google Sheet.
  6. Sur un second appareil, utilisez le même identifiant OAuth et le même identifiant de feuille, puis connectez-vous et synchronisez.

Chaque collègue peut créer sa propre base pour conserver un suivi personnel. Une feuille partagée met en commun les fiches et les totaux ; cette version ne sépare pas les tableaux de bord individuels dans une base commune. Aucun partage public n’est nécessaire. Les modifications simultanées d’une même fiche restent toutes dans l’historique ; la dernière révision est affichée.

En cas de problème

  • Origine refusée : vérifiez le protocole, le nom de domaine et le port exacts dans le client OAuth.
  • Accès refusé en mode test : ajoutez votre compte aux utilisateurs de test.
  • Feuille introuvable : vérifiez son identifiant et le compte propriétaire.
  • Onglet absent : utilisez la base fournie ou créez une nouvelle base depuis les Réglages.
  • Connexion expirée : reconnectez votre compte. Les saisies restent stockées sur l’appareil entre-temps.
