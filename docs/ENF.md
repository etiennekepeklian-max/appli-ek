# ENF — contenu par références et quantités

Le sigle est conservé tel qu’Étienne l’utilise ; son développement interne n’est pas confirmé. Une fiche possède un code ENF, un nom facultatif, des lignes référence/quantité et ses photos sources.

- Accès direct depuis l’accueil et le catalogue ; aussi dans Plus → Produits et emplacements. Recherche par code, nom ou référence de contenu.
- Photographier une ou plusieurs feuilles lance la lecture OCR locale, avec les mêmes ressources que les commandes. Une première utilisation demande leur téléchargement ; préparer l’OCR hors ligne avant une coupure.
- Le tableau proposé reste modifiable. Les références conservent leurs zéros ; les produits connus affichent leur nom. Une quantité illisible reste vide. Les nombres présents dans une description sont signalés pour relecture.
- Code ENF et quantités doivent être relus, puis la case de vérification cochée. Aucun enregistrement automatique de composition incertaine.
- Une photo identique est dédupliquée par empreinte. Des références répétées sont signalées et refusées à la validation ; le regroupement est une action explicite.
- Fermer conserve le brouillon sur cet appareil. Les photos restent disponibles pour réessayer la lecture. Les échecs OCR permettent aussi une correction manuelle du texte/tableau.
- Modifier écrit une nouvelle révision. Retirer conserve l’historique et l’annulation. Aucune réécriture d’anciennes commandes ni modification implicite des règles de picking.
- La composition et ses révisions sont sauvegardées dans les exports et dans l’onglet Google produit, sans ajouter d’onglet. Les photos suivent les documents privés.
- Les administrateurs modifient les compositions et peuvent les publier pour les opérateurs. Les photos sources ne sont pas transférées avec les paramètres d’équipe. Une ancienne publication de paramètres préserve les ENF inconnus de cet ancien client.
- Utiliser la version 1.11 ou suivante sur tous les appareils qui consultent une base contenant des ENF.

Limite : faute d’une feuille réelle fournie, la reconnaissance est vérifiée sur des feuilles synthétiques et du texte représentatif. La relecture reste nécessaire pour les mises en page, chiffres ou photos ambigus.
